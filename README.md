## What is it?
Web Workshop is a WordPress-inspired, block-based web app that lets users create and customize websites without coding.

## How to use?
1. Add any type of element you want (heading, paragraph, image, button).
2. Enter details of the element.
3. Click on the element to change its styles and content.
4. Click on "Export HTML" button.
5. Click copy to get the html.

## Tech Stack:
- Vite (React + tsx)
- TailwindCSS for styling
- `react-icons` for icons
- TypeScript for type-safety
- `react-hot-toast` for showing notification
